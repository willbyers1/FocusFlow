# FocusFlow 🌊 | Minimalist Task Dashboard

FocusFlow is a modern, responsive, and lightweight task management application designed for professionals who value simplicity. Built entirely with **Vanilla JavaScript**, it demonstrates clean DOM manipulation and persistent data storage techniques.

---

## ✨ Key Features

- **Dynamic Greeting:** Displays the current date and day in real-time.
- **Data Persistence:** Uses `LocalStorage` to ensure your tasks are saved even after closing the browser.
- **Sleek UI:** A professional dark-themed interface inspired by modern developer environments.
- **Fully Responsive:** Works perfectly on desktops, tablets, and mobile devices.
- **Optimized Performance:** Zero external libraries or frameworks for lightning-fast loading.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for better accessibility.
- **CSS3:** Modern layouts using Flexbox and custom CSS variables.
- **JavaScript (ES6+):** Functional logic and local storage integration.

```bash

2. Navigate to the Directory

3. Run the Project
You don't need a server! Simply open index.html in your favorite web browser:
```
